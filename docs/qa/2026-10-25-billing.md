## Por que 02/03/05 estão bloqueados (medido)

O container da API no QA **não tem nenhuma variável de billing/Stripe**, e o build do site não define
`VITE_BILLING_ENABLED`. Consequências observadas:

- `/assinar` logada mostra **"Continuar lendo" e "Minha assinatura"** — **não existe botão de checkout** para clicar;
- `/conta/assinatura` mostra **"Sem assinatura · Acesso liberado"** (com a flag desligada, o servidor não bloqueia);
- a API tem guarda própria: `if (!stripe.configured()) throw new AuthException(503, "Assinatura ainda não está disponível.")` (`BillingService.java:161`).

**Para destravar** (nomes exatos, do `application.yaml` e do build):

| Onde | Variável | Valor |
|---|---|---|
| API (QA) | `BILLING_ENABLED` | `true` |
| API (QA) | `STRIPE_SECRET_KEY` | `sk_test_…` |
| API (QA) | `STRIPE_WEBHOOK_SECRET` | `whsec_…` |
| API (QA) | `STRIPE_PRICE_ID` | `price_…` (plano mensal) |
| Site (build de QA) | `VITE_BILLING_ENABLED` | `true` |
| Stripe | endpoint do webhook | `https://api.qa.storyverse.2.29.42.104.sslip.io/api/v1/billing/webhook` |

## BILL-06 — financeiro (defeito encontrado e corrigido)

**Antes:** `/admin/financeiro` abria com **"Erro interno."** e ficava em "Carregando assinaturas…".
Log da API: `PSQLException: cannot execute INSERT in a read-only transaction` em
`BillingAdminService.summary(BillingAdminService.java:45)` — o método era `@Transactional(readOnly = true)`
mas chama `authz.audit(...)`, que grava em `admin_audit_log`; o mesmo em `subscription(id)`.

**Correção:** PR **[#52](https://github.com/axyonsoftwarehouse/story-verse-api/pull/52)** — `summary()` e
`subscription()` com `@Transactional` simples (a leitura grava auditoria); `subscriptions()` continua
`readOnly`. Teste de integração novo `billingSummaryWorksUnderRuntimeRole` roda no CI com Postgres.

**Depois (QA `80f04e1`):**

| Papel | Menu do admin | `/admin/financeiro` |
|---|---|---|
| `qa-admin` | Visão geral · Contas · Sanções · Features · Acervo · Fórum · Métricas · **Financeiro** · Auditoria | MRR **R$ 0,00**, ativas 0, em teste 0, inadimplentes 0, novas/canceladas 0/0, busca e filtros, "Nenhuma assinatura com esses filtros." — **sem** "Erro interno" |
